# Meetings

Records of **calls with APMG** — the client telling us what the product should do.

This is deliberately not [`sessions/`](../sessions/). A session doc records what a Claude Code session *built*; a meeting doc records what the client *asked for*, in their own words, with the decision and the owner attached. When the two disagree, the meeting doc is the requirement and the session doc is the evidence.

## Conventions

- **One file per call**, named `YYYY-MM-DD-<slug>.md`.
- **The raw transcript is kept** under [`transcripts/`](transcripts/), verbatim and unedited, with a header stating it is unproofread speech-to-text. Every quote in a meeting doc carries a timestamp so it can be checked against the audio.
- **ASR is treated as untrusted.** Speaker diarisation, names and numbers are mis-heard routinely. Where a figure matters, it is reconciled against the repo or the session docs in a table, and the discrepancy is stated rather than smoothed over.
- **Action items carry a re-checked state**, dated, verified against the tree at the time of writing — not the state assumed in the room.
- **Contradictions are recorded, not resolved.** If the client said two incompatible things (or asked for something the architecture can't do as described), that goes in its own section for an explicit re-decision.
